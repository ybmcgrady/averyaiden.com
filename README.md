# averyaiden.com

A playful, responsive homepage for Avery and Aiden. Built with plain HTML, CSS, and JavaScript; no installation or build step required.

## Preview

Open `index.html` in a browser, or serve this directory with any static web server:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Customize

- `index.html`: page text and sections
- `styles.css`: colors, layout, and CSS illustrations
- `script.js`: ideas for the “What-if machine”

Google Fonts is optional; local fallback fonts keep the page usable offline. The site has no analytics, forms, or account requirements.

## Hosting

Upload the three website files to any static host. For GitHub Pages, configure Pages to deploy from the repository’s main branch and root folder, then configure the custom domain and DNS for `averyaiden.com` in your hosting settings.
